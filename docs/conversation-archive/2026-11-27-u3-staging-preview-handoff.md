## Owner-reported issues and fixes

The owner reported missing Malay translations on learning surfaces, Daily Learning rendering [object Object], activities blocked by an approved-catalogue check, missing Malay Dashboard favourites, Malay saved-word clicks not opening in Your Collections, and confusing Malay Daily History labels.

Implemented:
- Structured Daily Learning prompt/option/explanation resolution prevents object values from reaching text rendering.
- Malay Daily Discovery catalogue IDs were reconciled with the current content pool; stale IDs are deactivated without deleting history.
- Dashboard Favorite Words includes a Bahasa Melayu group.
- Your Collections resolves Malay saved-word clicks through package-backed dictionary lookup, and opening a saved word synchronises learning-course/Profile translation selectors.
- Daily History separates Lessons from Daily Learning and labels Daily Topic, Daily Application, Daily Discovery and Daily Revision explicitly.
- Malay dictionary category filter remains available.
- Flashcards course switching preserves the equivalent Mixed Recall / Translation Recall slot between English and Chinese.
- Flashcards now consults the generated Malay Dictionary translation corpus before the smaller curated gloss map. Latest code commit for that resolver: a7c04fe84806e191d09519fa774e9cb069d1d037; current cache version: 3.0.0-ms13.
